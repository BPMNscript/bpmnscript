# BPMN coverage

Which BPMN 2.0 elements BPMNscript writes, and what the importer does with each one it meets in a `.bpmn` file.
The BPMNscript column is the statement that compiles to the element, or "not authored" when the language has no form for it; the statement's keys are in [packages/language/README.md](../packages/language/README.md).
The import column says whether `xmlToIr` imports the element, imports it changed or drops it with a warning (the category in parentheses), or refuses the file (the error class in parentheses); the exact conditions are in the [import contract](../packages/transform/README.md#the-import-contract).
Operaton's own extension elements (`operaton:` settings, input/output parameters, listeners, form fields) are not BPMN elements and are listed with the [IR shape](../packages/transform/README.md#ir-shape) instead.

## Activities

| BPMN element                                                        | BPMNscript                                           | Import                                                                                                                                                                             |
| ------------------------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bpmn:task`                                                         | `step X`                                             | imported                                                                                                                                                                           |
| `bpmn:manualTask`                                                   | not authored                                         | imported as `step`, warned (`rewritten`): history reports `task` where the source wrote `manualTask`                                                                               |
| `bpmn:userTask`                                                     | `user X(...)`                                        | imported; refused on a `bpmn:humanPerformer` beside `operaton:assignee` or a second `bpmn:humanPerformer` (`UnsupportedAssignmentError`)                                           |
| `bpmn:humanPerformer`, `bpmn:potentialOwner` on a user task         | `assignee`, `candidateUsers`, `candidateGroups` keys | imported onto those keys, warned (`rewritten`) naming the rewrite                                                                                                                  |
| `bpmn:performer`, `bpmn:resourceRole`, a role on any other activity | not authored                                         | dropped, warned (`unmappedConstruct`)                                                                                                                                              |
| `bpmn:serviceTask`                                                  | `service X(...)`                                     | imported; refused without a binding the engine reaches, with a `type` outside `external`, `mail`, and `shell`, or with an `operaton:connector` (`UnsupportedServiceTaskFormError`) |
| `bpmn:sendTask`                                                     | `send X(...)`                                        | imported, refused as a service task is                                                                                                                                             |
| `bpmn:businessRuleTask`                                             | `decide X(...)`                                      | imported, refused as a service task is, plus on a `decisionRefTenantId` or a `decisionRefBinding` of `versionTag` (`UnsupportedServiceTaskFormError`)                              |
| `bpmn:receiveTask`                                                  | `receive X(...)`                                     | imported                                                                                                                                                                           |
| `bpmn:scriptTask`                                                   | `script X` with a fenced body                        | imported; refused on an empty `scriptFormat`, on neither a body nor a resource, or on a `operaton:resource` in place of the body (`UnsupportedExtensionFormError`)                 |
| `bpmn:callActivity`                                                 | `call X(process: "...")`                             | imported; refused on a `caseRef`, a `calledElementTenantId`, a `versionTag` binding, or an `in`/`out` mapping outside the recognized shapes (`UnsupportedCallActivityError`)       |
| `bpmn:subProcess`                                                   | `subprocess X { }`                                   | imported; refused without a start event (`UnsupportedEventFeatureError`)                                                                                                           |
| `bpmn:subProcess` with `triggeredByEvent="true"`                    | `on <kind> { }`                                      | imported as an event handler, see the start event rows                                                                                                                             |
| `bpmn:transaction`                                                  | `attempt X { }`                                      | imported, a missing start event added, warned (`behaviourChanged`); `method`, `protocol`, and `triggeredByEvent` dropped, warned (`unmappedConstruct`)                             |
| `bpmn:adHocSubProcess`                                              | not authored                                         | refused (`UnsupportedElementError`)                                                                                                                                                |
| `bpmn:multiInstanceLoopCharacteristics`                             | `for each x in c`, `for 3`, with `sequentially`      | imported; refused on an event handler, beside an `operaton:outputParameter`, or with a `loopCardinality` body the script cannot spell (`UnsupportedLoopCharacteristicsError`)      |
| `bpmn:standardLoopCharacteristics`                                  | not authored                                         | dropped, warned (`unmappedConstruct`): Operaton runs the activity once regardless                                                                                                  |
| `startQuantity`, `completionQuantity` other than `1`                | not authored                                         | dropped, warned (`unmappedConstruct`): Operaton never reads either                                                                                                                 |

## Gateways

| BPMN element              | BPMNscript                                         | Import                                                                                                                                                                                                                                                              |
| ------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bpmn:exclusiveGateway`   | `if` / `else if` / `else`, `while`, `do ... while` | imported; refused on a shape `BpmnParse.validateExclusiveGateway` fails, such as two unconditioned routes (`UnsupportedGatewayShapeError`); a route with no condition listed before a conditioned one prints in its place as an `if (true)` head                    |
| `bpmn:parallelGateway`    | `parallel { { } { } }`                             | imported                                                                                                                                                                                                                                                            |
| `bpmn:inclusiveGateway`   | `parallel { if (c) { } else { } }`                 | imported                                                                                                                                                                                                                                                            |
| `bpmn:eventBasedGateway`  | `await { <kind>(...) { } <kind>(...) { } }`        | imported; refused when a branch leads to anything but a catch event or the gateway carries `asyncAfter` (`UnsupportedEventFeatureError`), or without an id (`UnsupportedDocumentError`); `instantiate` and `eventGatewayType` dropped, warned (`unmappedConstruct`) |
| `bpmn:complexGateway`     | not authored                                       | refused (`UnsupportedElementError`)                                                                                                                                                                                                                                 |
| `name` on any gateway     | not authored                                       | imported and then left out of the script, warned on print (`label`)                                                                                                                                                                                                 |
| a listener on any gateway | not authored                                       | dropped, warned (`extensionAttribute`)                                                                                                                                                                                                                              |

## Events

### Start events

| BPMN element                                                                     | BPMNscript                                     | Import                                                                                                                                       |
| -------------------------------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `bpmn:startEvent` with no definition                                             | `start X`                                      | imported; a second one on the process refused (`UnsupportedEventFeatureError`); any start without an id refused (`UnsupportedDocumentError`) |
| message start                                                                    | `start X message("Name")`                      | imported; refused when the name is an expression (`UnsupportedEventFeatureError`)                                                            |
| signal start                                                                     | `start X signal("Name")`                       | imported                                                                                                                                     |
| timer start                                                                      | `start X timer("PT1H")`, `at:`, `every:`       | imported; refused without an id (`UnsupportedDocumentError`)                                                                                 |
| conditional start                                                                | `start X condition(expr)`                      | imported                                                                                                                                     |
| error, escalation, or compensation start on the process                          | not authored                                   | refused, since Operaton ignores the trigger (`UnsupportedEventFeatureError`)                                                                 |
| any other definition on a process start                                          | not authored                                   | refused (`UnsupportedEventDefinitionError`)                                                                                                  |
| a start with a definition inside a sub-process or transaction                    | not authored                                   | refused (`UnsupportedEventFeatureError`)                                                                                                     |
| a second start event inside a `bpmn:subProcess` or `bpmn:transaction`            | not authored                                   | refused (`UnsupportedEventFeatureError`)                                                                                                     |
| an event sub-process start: error, escalation, message, signal, timer, condition | `on <kind>(...) { }`, `alongside` when allowed | imported as the handler's trigger; refused with more or fewer than one definition (`UnsupportedEventFeatureError`)                           |
| an event sub-process start carrying a cancel, link, or terminate definition      | not authored                                   | refused (`UnsupportedEventDefinitionError`)                                                                                                  |
| an event sub-process start: compensation                                         | `on compensation { }` inside a `subprocess`    | imported inside a sub-process or transaction; refused on the process or in another handler (`UnsupportedEventFeatureError`)                  |

### End events

| BPMN element                       | BPMNscript                         | Import                                                                                                                                                                                                                           |
| ---------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bpmn:endEvent` with no definition | `end X`                            | imported                                                                                                                                                                                                                         |
| terminate end                      | `end X terminate`                  | imported                                                                                                                                                                                                                         |
| cancel end                         | `end X cancel` inside an `attempt` | imported inside a `bpmn:transaction`; refused anywhere else (`UnsupportedEventFeatureError`)                                                                                                                                     |
| error end                          | `throw error(CODE)`                | imported; refused without an `errorRef` or with a root carrying no code (`UnsupportedEventFeatureError`)                                                                                                                         |
| escalation end                     | `throw escalation(CODE)`           | imported; refused without an `escalationRef` or with a root carrying no code (`UnsupportedEventFeatureError`)                                                                                                                    |
| message end                        | `throw message("Name")`            | imported; refused with a connector (`UnsupportedEventFeatureError`), or a `type` other than `external`, or `external` with no `topic` (`UnsupportedServiceTaskFormError`); `type="external"` with a `topic` imports as a binding |
| signal end                         | `throw signal("Name")`             | imported                                                                                                                                                                                                                         |
| compensation end                   | `throw compensation`               | imported; refused with an `activityRef` naming one activity, or `waitForCompletion="false"` (`UnsupportedEventFeatureError`)                                                                                                     |
| any other definition on an end     | not authored                       | refused (`UnsupportedEventDefinitionError`)                                                                                                                                                                                      |

### Intermediate throw events

| BPMN element                                     | BPMNscript              | Import                                                                                                                                                                                                                                                                |
| ------------------------------------------------ | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bpmn:intermediateThrowEvent` with no definition | not authored            | imported as `step`, warned (`rewritten`): history reports `task`                                                                                                                                                                                                      |
| escalation throw                                 | `emit escalation(CODE)` | imported                                                                                                                                                                                                                                                              |
| message throw                                    | `emit message("Name")`  | imported; refused with a connector (`UnsupportedEventFeatureError`), or a `type` other than `external`, or `external` with no `topic` (`UnsupportedServiceTaskFormError`); `type="external"` with a `topic` imports as a binding, the same rule a message end follows |
| signal throw                                     | `emit signal("Name")`   | imported                                                                                                                                                                                                                                                              |
| compensation throw                               | `emit compensation`     | imported; refused with an `activityRef` naming one activity, or `waitForCompletion="false"` (`UnsupportedEventFeatureError`)                                                                                                                                          |
| link throw                                       | `emit link("Name")`     | imported; refused when it names no link or a sequence flow leaves it (`UnsupportedEventFeatureError`)                                                                                                                                                                 |
| error throw                                      | not authored            | refused, BPMN has no intermediate error throw (`UnsupportedEventFeatureError`)                                                                                                                                                                                        |
| any other definition on an intermediate throw    | not authored            | refused (`UnsupportedEventDefinitionError`)                                                                                                                                                                                                                           |

### Boundary events

| BPMN element                                                           | BPMNscript                                                           | Import                                                                                                                                                           |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| error boundary                                                         | `on Host: error(CODE) { }`                                           | imported; refused with `cancelActivity="false"` (`UnsupportedEventFeatureError`)                                                                                 |
| escalation, message, signal, timer, or conditional boundary            | `on Host: <kind>(...) { }`, `alongside` for `cancelActivity="false"` | imported                                                                                                                                                         |
| cancel boundary                                                        | `on Block: cancel { }` beside an `attempt`                           | imported on a `bpmn:transaction` host; refused on any other host, with `cancelActivity="false"`, or as a second cancel boundary (`UnsupportedEventFeatureError`) |

| any other definition on a boundary                                     | not authored                                                         | refused (`UnsupportedEventDefinitionError`)                                                                                                                      |
| a boundary with no `attachedToRef`, an incoming flow, or no definition | not authored                                                         | refused (`UnsupportedEventFeatureError`)                                                                                                                         |
| a boundary without an id, other than a compensation boundary           | not authored                                                         | refused (`UnsupportedDocumentError`)                                                                                                                             |

## Sequence flow

| BPMN element                                                                      | BPMNscript                                                                                    | Import                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `bpmn:sequenceFlow`                                                               | never written: steps run top to bottom, `goto X` for a jump                                   | imported, one without an id under an id minted from its ends; the printer rebuilds blocks from the flow graph and writes `goto` where no block fits; a route it cannot place is left out, warned on print (`droppedEdge`, `degradedSplit`) |
| `bpmn:conditionExpression`, and a conditional event definition's `bpmn:condition` | the condition of `if`, `while`, `do ... while`, a `parallel` branch, and of `condition(expr)` | imported; refused with a `language` attribute or an `xsi:type` other than `tFormalExpression` (`UnsupportedConditionExpressionError`)                                                                                                      |
| `default` on a gateway                                                            | `else`, the fallback branch                                                                   | imported as written (`mapDefaultingGateway`); on an exclusive gateway the shape check above can still refuse the gateway around it                                                                                                         |
| `default` on an activity                                                          | `else`, the fallback branch                                                                   | imported when it names one of the activity's own outgoing flows; dropped, warned (`unmappedConstruct`) otherwise                                                                                                                           |
| `name` on a sequence flow                                                         | not authored, derived from the condition                                                      | warned (`label`) when it differs from the derived label                                                                                                                                                                                    |
| a flow into or out of an event sub-process                                        | not authored                                                                                  | refused, `BpmnParse.parseSequenceFlow` fails on it (`UnsupportedEventFeatureError`)                                                                                                                                                        |
